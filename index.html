Version Details & Release Notes

Version 1.4.0 Current
  • • Added Clinic Setup section on Admin screen for CanImms Location (Zone + Number) and daily vaccine Lot # entry across all 18 clinic vaccines, displaying active products and lot numbers on both Admin (with Edit/Update) and Nurse Station (read-only).
Version 1.3.9
  • • Added "Could not vaccinate" (Not eligible, Patient declined, Contraindicated) and "Pano Notes" checkboxes to Nurse Station patient cards, logging NoVax, Reason, and Pano columns and displaying totals on the Admin screen.
Version 1.3.8
  • • Added multi-seat group assignment on the Recovery screen so staff can assign and track multiple chairs under a single group ticket number.
Version 1.3.7
  • • Added "Assign Group" checkbox on Registration to record multi-person family/group visits on a single ticket, displaying group badges on Nurse and Recovery screens and counting total humans served in Admin metrics.
Version 1.3.6
  • • Added 5-minute neighbor-anchored sequence gap detector on the Registration screen with one-click pre-fill or skip/dismiss controls to compensate for missing queue entries due to network issues or human error.
Version 1.3.5
  • • Fixed Public Display audio repeat bug: when a client finishes with their nurse and a previously called client moves up into the primary NOW SERVING box, the display updates visually without re-chiming or re-announcing them.
Version 1.3.4
  • • Added seat-to-seat client relocation on the Recovery screen: tap "Move" on any occupied chair and tap any vacant chair to transfer while keeping their active countdown timer intact. *Feedback from team ❤️
Version 1.3.3
  • • Added one-tap Recovery seating: tap a client pill in the ready banner, then tap any vacant chair to assign immediately.
  • • Replaced fixed Recovery grid dropdowns with flexible numeric inputs supporting any number of rows and seats per row.
Version 1.3.2
  • • Solved the speech synthesis bug—Station E is now properly pronounced as "Station E" instead of "Station East". Station E has been officially reinstated.
  • • Fixed "Call Patient Again" recall audio and Public Display ordering using LastCalledTime instead of initial registration Timestamp.
  • • Prevented duplicate recovery auto-discharge calls across multiple open terminals and added a live connection status badge.
Version 1.3.1
  • • Added dynamic Recovery grid layout configuration (selectable rows and seats per row) persisted locally.
  • • Fixed dropdown interruption bug: background polling now safely defers re-rendering when a staff member has a seat dropdown open.
Version 1.3.0
  • • Added Recovery Time selector (15m, 30m, 45m, Declined) on Nurse Station cards for Vaccination visits.
  • • Added Recovery Station screen with live countdown timers from nurse release, early exit clearing, and automatic timeout discharge.
Version 1.2.0
  • • Added Return to Queue functionality at Nurse Stations with confirmation popup to avoid returning client to queue by accident.
  • • Added terminal authorization pin to prevent unauthorized access.
  • • Updated service type descriptions on registration screen.
  • • Added EvoQueue branding and clickable version release notes popup viewer.
  • • Changed active call colouring on public display screen to avoid staff outing themselves when pointing out visual similarities to a popular adult site that Sonja has never visited.
  • • Increased station font and overall scale of public display screen
